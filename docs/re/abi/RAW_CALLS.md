# Calls via raw vtable slot index (`Vtable[N]`)

Generated by `tools/abi.py build` — do not edit by hand.

`reinterpret_cast<FnX>(Vtable[0x1C / 4])(Obj, ...)` is a call that the compiler does not type-check **at all**: neither argument count, nor types, nor calling convention. Every such line reinvents the foreign method signature from scratch. This is a direct consequence of an interface not being exposed publicly — see [../cross_dll_protocol.md](../cross_dll_protocol.md) and [AUDIT.md](AUDIT.md).
